# Bilder

Alla foton med WebP-format blir automatiskt klickbara och öppnas i bildvisaren.
Galleriet på Boendet visar fem rutor; fler bilder i galleriet nås via "+N bilder".

Foton sparas som WebP i två bredder (800 och 1600 px) så att mobiler laddar den
mindre filen. Skapa nya med samma namnmönster: `namn-800.webp` och `namn-1600.webp`.

## På plats

| Fil                  | Används på                                          |
|----------------------|-----------------------------------------------------|
| `vardagsrum-*.webp`  | Start (Boendet), Boendet (galleri), Boka            |
| `sovloft-*.webp`     | Boendet (galleri) – balkongdörren                   |
| `sovloft-sang-*.webp`| Boendet (galleri) – dubbelsängen                    |
| `kok-oversikt-*.webp`| Boendet (galleri)                                   |
| `matplats-*.webp`    | Boendet (galleri)                                   |
| `badrum-*.webp`      | Boendet (galleri) – handfat                         |
| `badrum-dusch-*.webp`| Boendet (galleri, i bildvisaren)                    |
| `kok-*.webp`         | Start (intro), Boendet (galleri)                    |
| `bastu-*.webp`       | Start (bastukort), Bastu & Bad                      |
| `bastu-eld-*.webp`   | Bastu & Bad (toppbild)                              |
| `spabad-*.webp`      | Start (spabadskort), Bastu & Bad, Boka              |
| `svamp-*.webp`       | Start – Upplevelser                                 |
| `entre-*.webp`       | Start – Hundvänligt                                 |
| `backen-*.webp`      | Start – Upplevelser                                 |
| `vardar-*.webp`      | Boka, Kassa (rund porträttbild på värdarna)         |
| `og-image.jpg`       | Förhandsbild när länken delas (1200×800)            |
